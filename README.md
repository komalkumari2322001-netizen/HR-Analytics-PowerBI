# HR Analytics Dashboard – Power BI

## Project Overview

This project is an interactive **HR Analytics Dashboard** developed using Microsoft Power BI. The dashboard analyzes employee data to understand workforce distribution, employee attrition, job roles, satisfaction, and other key HR metrics.

The project demonstrates how raw HR data can be transformed into meaningful visual insights using Power BI.

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning & Transformation
- Data Visualization

## Project Objectives

- Analyze overall employee headcount and attrition.
- Understand attrition across departments and job roles.
- Analyze employee demographics and workforce distribution.
- Identify patterns related to employee satisfaction and tenure.
- Build an interactive dashboard for HR analysis.

## Key Analysis

The dashboard includes analysis of:

- Employee Count
- Attrition Count & Attrition Rate
- Department-wise Attrition
- Job Role-wise Attrition
- Employee Age & Gender Distribution
- Job Satisfaction
- Years at Company
- Employee Experience

## Dashboard

The Power BI dashboard contains interactive KPIs, charts, and filters that allow users to explore HR metrics and identify employee attrition patterns.

## Skills Demonstrated

**Power BI | DAX | Power Query | Data Cleaning | Data Transformation | Data Visualization | KPI Analysis**

## Project Outcome

The project demonstrates the ability to transform HR data into an interactive Power BI dashboard and derive useful insights from employee and attrition data.
