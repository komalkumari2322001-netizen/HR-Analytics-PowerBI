# Project Documentation

## Objective

The objective of this project is to analyze employee data and understand workforce and attrition patterns using Microsoft Power BI.

## Analysis Performed

- Overall employee headcount and attrition analysis
- Department and job role-wise attrition
- Employee demographic analysis
- Job satisfaction analysis
- Employee tenure and experience analysis
- KPI and interactive dashboard development

## Dashboard Development

The dataset was cleaned and transformed using Power Query. DAX was used to create required calculations and KPIs, followed by interactive visualizations to present the analysis.

## Key Outcome

The dashboard provides an interactive view of important HR metrics and helps identify employee attrition patterns and workforce trends that can support HR analysis and decision-making.
